# Portafolis 3D

Aquest projecte esta fet amb A-Frame i esta pensat per funcionar amb models 3D en format `.glb`.

## Assets

- Posa els models dins `assets/`.
- El format recomanat es `.glb`, perque empaqueta model, materials i textures en un sol fitxer.
- Tambe pots usar `.gltf`, pero normalment hauras de conservar al costat el `.bin` i la carpeta de textures.

## Webs utils

- Models 3D: https://sketchfab.com/features/gltf
- Personatges animats: https://www.mixamo.com/
- Convertir animacions de Mixamo a GLB: https://mixamo2gltf.com/
- Veure si un GLB funciona be: https://glbviewer.com/
- Convertir, escalar o arreglar models: https://www.blender.org/

## Com canviar els projectes

Al fitxer `index.html`, busca `projecte1`, `projecte2`, `projecte3` i `projecte4`.
Canvia els textos i els enllacos de `external-link="href: ..."` pels teus projectes reals.
